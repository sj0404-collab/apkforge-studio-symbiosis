# Тестовые файлы: почему синтетические и что они доказывают

В репозитории лежат три настоящих контейнера, а не заглушки с расширением:

| Файл | Формат | Размер | Что внутри |
|---|---|---|---|
| `Games/Sonic Mania [01004E300BD5C000][v0].nsp` | NSP | 136 КБ | PFS0 с двумя NCA (основной + `.cnmt.nca`) |
| `Games/Metroid Dread [010093801237C000][v0].xci` | XCI | 129 КБ | заголовок геймкартриджа, корневой HFS0, партиция `secure` |
| `Games/Hollow Knight [0100633007D48000][v0].nsz` | NSZ | 17 КБ | PFS0, внутри NCZ: заголовок NCA + `NCZBLOCK` из кадров zstd |

Они записаны `tools/make-fixtures.py` строго по тем смещениям, которые
читает **наш собственный** `patch/symbiosis/rom_tools.cpp`, и скрипт умеет
ходить обратно тем же алгоритмом:

```
ok    Sonic Mania … .nsp: nsp, 139407 Б
ok    Metroid Dread … .xci: xci, 132096 Б
ok    круговорот → Metroid Dread … .nsp (nsp, 114805 Б)
ok    Hollow Knight … .nsz: nsz, 17685 Б
ok    круговорот → Hollow Knight … .nsp (nsp, 32845 Б)
```

То есть `XciToNsp` и распаковка NSZ/NCZ проверены на реальных байтах, а не
описаны.

## Почему не настоящие дампы и не настоящие ключи

* Настоящий NSP — гигабайты, в репозиторий такое не кладут.
* Ключи консоли и прошивку **нельзя** брать «для тестов»: prod.keys привязаны
  к устройству, их публикация нарушает и лицензию, и приватность владельца.
  Поэтому содержимое — честная заглушка: заголовок NCA на месте, `NCA3` по
  0x200, дальше нерасшифровываемое тело.
* Именно из-за отсутствия ключей эти файлы **не запускаются**, и приложение
  так и говорит: «ядро не прочитало заголовок · проверьте ключи или распакуйте
  файл». Это не дефект скриншота — это правда о файле без ключей, и она
  совпадает с тем, что пользователь видит с настоящим дампом без prod.keys.

## Что всё-таки доказывают скриншоты

Библиотека — это ответ на вопрос «какие файлы есть и что с ними можно
сделать», и он не требует криптографии:

* все три формата **видны** в списке (а раньше виделся один);
* NSZ помечен как сжатый и открывает «Распаковать» — кнопка, которая
  ставит именно этот файл в очередь конвертера;
* XCI и NSP без ключей попадают в «Почему не видно» с причиной словами;
* сводка считает их честно: `3 файла · 0 игр · 1 сжатый → Конвертер`;
* конвертер показывает настоящий выход распаковки (`converted-*.nsp`,
  собранный из NSZ), а не пустой список.

Запуск с настоящими ключами и замер FPS — на телефоне, за вами.

## Как пересобрать

```bash
python3 tools/make-fixtures.py --out public/fixtures     # записать и проверить
node tools/shots.mjs                                     # снимки в shots/
node tools/shots.mjs --studio                            # плюс снимок студии
```

`--studio` требует запущенной студии: `npm run dev`.
