# Превью нового интерфейса

Четыре экрана в новой палитре: библиотека, «Два ядра», «Инструменты», руководство.

**Цвета не на глаз.** `make_preview.py` читает `palette.json`, а тот печатает сам
Kotlin-код `patch/android/utils/SymbiosisTheme.kt` — те же числа, что уедут в APK.
Если в приложении цвет изменится, картинки придётся пересобрать, и расхождение
будет видно сразу.

Это предпросмотр вёрстки, а не снимок с телефона: эмулятор здесь без KVM не
запускается. Он проверяет то, что можно проверить до сборки — порядок блоков,
переносы длинных подписей, контраст текста на цветных плашках.
